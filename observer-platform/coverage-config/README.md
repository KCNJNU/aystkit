# 传感器覆盖与盲区配置

React + TypeScript + Three.js，Vite 构建。页面 `/coverage` 沿用观测站登录审批；
只在浏览器内计算几何覆盖，配置保存在本机，可导入导出，不控制机器人。

运行 `npm ci`、`npm test`、`npm run build`，输出至 `cloud/frontend/coverage`。
生产服务器不需要 Node.js，不使用运行时 CDN。

坐标：底盘几何中心的地面投影为原点，X 前、Y 左、Z 上。界面长度统一显示 cm，面积显示 cm²，最多一位小数；未编辑的原始值保留计算精度。内部计算及兼容的导入／导出 JSON 继续使用米和平方米。
Yaw 0°前、90°左、180°后、−90°右；Pitch 正值朝下。
量程按三维直线距离计算。切片按网格中心采样，排除底盘占地；
遮挡仅考虑底盘实体。统计是几何估计，不能代替真实检测率或环境障碍物分析。

默认值依据：

* A062 规格书第 3/7 页：500 万相机 2592×1944，水平110°±3°、垂直90°±3°。
* A0588 规格书第 3 页：200 万相机 1920×1080，水平84°±5°、垂直54°±5°。
* 项目 `src/mid360_nav2/config/nav2_params.yaml` measured:true：
  底盘1.00×0.65×0.25m，MID360位置(.4,0,1.15)m，下俯29°。
* MID360 本体水平360°、垂直−7°～52°（中心偏置+22.5°），来自项目costmap配置。
* 后相机 ArUco 安装配置换算到底盘中心：(-.50,0,.91)m，朝后、下俯36°。
* P100R软件视场约68.984°×47.498°；现有标定合成深度光学原点
  (.338623,.014910,.784392)m，Yaw−.693°、下俯25.255°。
  原外参另含约2.399°横滚，此Yaw/Pitch模型省略。
* 前、左、右相机安装位置与框架尺寸为示意值，需按实物调整。

所有最小/最大距离均为分析参数，不是厂商测距或识别保证；STVL清除范围不等于硬件量程。

## 拖拽与布局对比

开启“调整位置”后，拖动彩色设备点可在所属安装空间盒内沿 X、Y、Z 三轴移动，数值输入和滑条同样受盒体边界限制；支持三轴手柄、1 cm 拖动吸附及 Esc／失焦撤回。支架实体沿所选杆件移动，盒内比例保持。前相机与深度相机共用一个支架，支架仍沿前侧中梁左右移动，两台相机可在盒内独立调整。空白区域用于旋转视图。

“设为对比基准”保存当前完整配置，“恢复基准”恢复该配置。基准与当前布局各自保存到当前浏览器。比较时两套传感器布局统一使用当前高度切片、分析区域、网格、遮挡开关和底盘尺寸；改变分析条件会同时重算基准，不把不同面积或高度的数据相减。覆盖率与重叠率差值单位为百分点，盲区差值在界面使用 cm²。

页面保留字段名称、单位、统计结果和错误反馈，不显示帮助问号、悬浮提示、操作说明或成功通知。

## 左右相机位置与角度推荐

配置框架和其他传感器后，点击“推荐左右相机位置与角度”。前后相机、P100R、雷达、框架、分析区域和光学视场均保持当前值。推荐先将两侧安装盒的中心X对齐到原两中心的均值，再让两盒沿各自X梁同方向、同距离移动；左右偏航互为反数，俯角相同。起点对齐的左右校正量可以不同，后续共同位移相同；相对原布局的总移动量分别等于该侧起点校正量加共同位移，界面会分开显示。

盒内相对坐标、Y/Z和安装盒尺寸固定，设备随盒体整体移动。对称约束针对安装盒中心X和相机角度，表格显示的相机光学原点坐标仍由各自盒内点位推导，不将盒内点位改成全坐标镜像。共同位移范围使用对齐后两侧梁可安装范围的交集；按整个安装盒的前后边缘限位，盒体不得超出梁端。已有导入配置保持原样，只有应用推荐时才调整；左右相机必须同时启用才能启动对称推荐。

计算在浏览器Worker中运行，默认策略为“整体覆盖不下降 → 尽量靠近横梁中点 → 再改善近场”。先保留符合安装边界、位置对齐、镜像角度及整体覆盖保护的方案；优先选择两盒共同中心距实际横梁中点更近的方案，在距离相同时依次比较近场覆盖、整体覆盖，最后减少位置和角度调整。横梁中点是实际梁段的中点，区别于起点对齐时使用的原两盒中心均值。界面显示横梁中点X、推荐两盒共同中心X、前后方向偏移及当前→推荐的距中点距离；原始校正量和后续共同位移仍单独显示。若覆盖或安装约束使中点不可用，会显示实际偏移，不承诺一定能到X=0。

默认近场为距底盘XY矩形外缘1 m以内、且不在底盘前端以外的区域；界面展示近场总覆盖、盲区及左侧、右侧、左后（X≤0）、右后和后方分区。默认 `coverageProtection='overall'` 仅对整体覆盖设置不下降的硬约束，近场总覆盖及各分区可以下降；下降格数、覆盖率与盲区变化会按实际结果标红显示，不将这些近场下降误报为整体覆盖保护失败。兼容 `coverageProtection='all-regions'` 或未注明策略的旧结果时，整体、近场总覆盖及五个分区均保留不下降保护，界面按该结果所用策略说明。

粗候选搜索后细化共同偏航幅度、共同俯角及位置，相关位置按0.5 cm步长搜索，并对不可能优于当前居中程度的区间做安全剪枝。默认左侧偏航45°～135°，右侧始终取对应的相反角度；共同俯角0°～85°。当前布局用于覆盖保护比较及无可行方案时退回；仅将满足所选策略保护、位置对齐、镜像角度和安装边界的候选作为推荐，最终用原几何算法复核。有限角度网格和局部细化不构成连续空间的全局最优证明；统计仍只考虑底盘实体遮挡。

结果仅列左右相机的位置、偏航和俯角，先展示居中距离，再展示近场、各分区及整体覆盖率和盲区的真实变化，并显示位置与角度的对称状态。预览用空心位置标记与朝向箭头显示推荐；仅角度改变的对称方案也可以预览和应用。点击“应用到布局”才更改当前布局，可撤销；不改写对比基准。参数变化或取消会清除过期计算。没有满足全部约束的推荐时保留当前布局，显示原因并隐藏推荐位置及居中数值，不把当前不合格的布局当成推荐方案。

## 塑料支架与安装空间

当前 layoutRevision=8。8 个设备点对应 7 个有界空间盒，前相机和 P100R 共用 front 盒。左右相机默认安装于中梁，MID360 默认使用与相机相同的塑料支架，开口朝车架内侧（前侧顶梁对应 −X）；默认支架尺寸及离梁距离是可编辑估计值，照片不提供实测尺寸。传感器仍以点显示，支架外形与半透明长方体用于区分实体安装件和允许调整的空间。

“安装空间”可分别调整 X／Y／Z 长宽高。后视相机、蓝海二维雷达和底部 STL-19P 的安装盒位于所在横梁下方，位置面板提供 X／Y 偏移与正值“距横梁下表面”，无需自行计算负 Z 偏置。该距离是盒体最高处（含顶板螺钉）至梁下表面的净距，默认 1 cm，可在 0～50 cm 内按 0.1 cm 调整；贴梁夹脚和连接支臂不计入盒体净距。修改盒高、板厚、杆件位置或梁高时，下挂位置自动重算并保留该间隙。其他支架继续提供三轴偏置。

展开“支架与安装杆件”可调整塑料厚度、支架外形、固定杆件及沿梁位置。空间尺寸、偏置、塑料板厚度、设备世界坐标、量程及车架尺寸统一显示 cm，最多一位小数。支架锚点始终在杆件上，设备 inSupport 为归一化盒内坐标，所有入口均限制为0～1。设备朝向与视野独立设置；下挂表示盒体相对于横梁的位置，盒体采用正常的侧向开口，MID360 继续朝框架内侧。设备点随安装盒位置同步移动，几何覆盖与盲区随新的实际模型位置重新计算；光学角度和盒内相对点位保持。框架、支架及环境不加入遮挡计算。

旧配置与基准在载入时迁移一次，保留原有光学参数与前侧共享板初始点位，左右原上梁默认挂载改为中梁。导出JSON包含完整 supports 和 inSupport，刷新与导入均使用相同约束。基准比较保留各自支架和盒内位置，在当前统一车架与切片条件下重算。

版本 7 会将旧版 MID360 默认凸台改为相机同款支架，并把原默认零前后偏置移向车架内侧半个盒深；已有自定义尺寸、非零偏置和盒内相对点位保留。当前版本再次导入、刷新均不重复迁移，用户重新选择的支架外形也会保留。

版本 8 将后视相机、蓝海雷达和底部 STL-19P 的旧布局修正为横梁下挂，保留已有尺寸、沿梁位置、X／Y 偏移、盒内相对点位与光学参数。保存配置新增三处的 `beamGap`（内部单位米），Z 中心偏置由横梁下表面、盒体尺寸、板厚与间隙推导；已有浏览器配置和对比基准通过同一规则载入，不需清空。
