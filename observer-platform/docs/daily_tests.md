# 每日测试统计

入口为观测页左侧 **每日测试**，或 `https://aystkit.cn/#tests`。已批准的账号可查看、下载和调整统计状态；未登录和待批准账号无法访问。页面上的“开始测试、暂停统计、继续统计、结束测试”只管理记录，不向小车发送行驶指令。

## 统计口径

新测试开始前需登记测试人员姓名，去除首尾空白后为 1–60 字。姓名随本次测试保存，暂停、继续和结束时保持不变；登录账号仍单独记录为操作人。历史未登记的记录显示“未登记”。测试名称可选，最多 60 字。测试时间按手动开始至结束期间的运行区间累计，包含测试过程中的静止时间，暂停期间不计时。关闭网页不结束测试；刷新、重新登录和多个终端查看使用同一份后台状态，不重复计数。跨午夜的时长和里程按北京时间拆到各自日期。

移动距离来自工控机导航里程计的连续有效测量，按实际行驶轨迹累计；指令速度和地图定位坐标不代替实际移动。界面统一显示米、一位小数。没有有效里程数据时显示“—”，不填成零；只有部分时间有有效数据时标为“部分记录”。有效里程数据的时间与手动测试时长分别保存。

开始或暂停等操作保存到后台后，采集端需要确认新的统计版本。确认前显示“同步中”；采集离线、里程数据中断和异常会单独标明。断流、重启及不可信的位置跳变不通过两点连线补算，避免将数据间断算成实际路程。里程计的累计误差仍会影响测距结果。

## 测试问题交接

每日测试页的“测试问题记录”用于登记人工发现的问题。问题按车辆共享，记录中保留登记账号、北京时间和问题分类；不要求问题登记者与下一次测试者是同一人。当天可以继续添加问题，不会改变正在进行的测试计时。

第二天打开测试页时，前一天的问题会列成清单。每一项都要选择“✓ 已解决”或“✕ 仍存在”后才能开始当天测试。选择“仍存在”会把问题继续带到下一天；选择“已解决”会关闭它。复核动作保存复核账号、日期和时间，任一已批准账号完成当天复核后，其他账号看到的开始条件也会同步更新。问题记录和复核结果保存在后台 SQLite 中，随每日测试数据一起备份。

## 查看和下载

页面显示今日时长、距离、测试次数和数据状态，近 7 日趋势、近 30 日每日记录及可展开的测试明细。时间使用北京时间；CSV / JSON 下载与每日表采用相同统计口径。每日记录按当天参与测试的姓名去重汇总，跨日测试显示在各自日期；CSV 在原有 6 列后增加“测试人员”，JSON 同时保留每日名单和每次测试的姓名。记录从模块启用及明确开始的测试累积，不推算启用前的测试历史。

同时有其他页面改变统计状态时，当前页面会重新读取后台结果；提交失败时保留原状态并刷新确认。页面退出或进入后台后停止轮询，统计保存和实际采集由后台继续执行。
