# 观测页面的当前接口清单

页面只展示当前部署有生产者或适配链路的模块。设备没启动、没有新消息、发布者为零或字段值为空，不会让已接入模块消失。本次仅调整显示清单；已有协议和只读订阅保持兼容。

## 已移除的占位项目

| 项目 | 当前部署证据 | 页面处理 |
| --- | --- | --- |
| NPU 指标及独立页面 | `collector/legacy/system_metrics.py` 只有 RK3588 设备调频路径适配，当前采集链路没有本机 NPU 监测接口 | 移除导航、曲线、总览卡和状态事件 |
| 模型运行时、推理帧率与延迟 | 现有系统采集器将 `modelName/inferenceFps/inferenceLatencyMs` 固定为 `None`；并非 Jetson YOLO 的实际运行状态 | 移除空闲模型占位，不影响视频识别结果 |
| 运动指令与刷子目标转速 | 当前工控机 RX_ONLY 遥测生产者只读串口，不接收 `/cmd_vel`，也不记录目标指令 | 运动图保留实际反馈，刷卡保留实际转速、在线、故障和通信状态 |
| 刷子内部状态 | 当前遥测生产者没有对应实际字段更新 | 移除该状态单元 |
| 独立 DDS 节点发现卡 | 原卡重复使用整体 ROS 话题状态，没有独立发现探针 | 移除重复卡，保留话题状态、发布者和类型检查 |
| 控制冲突检查、部署模式与控制 API 状态占位 | 原内容是固定“未检查/远程工控机/已禁用”文案，不是采集指标 | 移除静态监测项 |
| AMCL 和对接预览旧状态 | 当前项目不启用 AMCL，`/aruco_docking_preview/state` 没有当前生产者 | 只从感知列表及详细话题表去除这两个旧接口 |
| `fisheye/usbRear/usbPort21` 旧相机别名 | 当前六路显示源为 `usbFront/usbLeft/usbHub2/usbHub3/color/depth`；旧默认图像别名不在当前链路 | 从感知设备合并列表隐藏旧别名和两条旧鱼眼图像话题，不删除物理设备 |

`/fisheye_aruco/*` 是实际视觉识别接口，不等同于旧鱼眼原图别名；这些识别话题以及 `/aruco_docking/state` 保留。

## 保留的实际接口

保留系统 CPU、内存、磁盘、温度、网络；机器人云端心跳；底盘电压、左右轮与线/角速度实际反馈；刷子和推杆的实际反馈；STM32 数据页及有效帧、校验错误、无效帧等真实解析统计。

MID360、蓝海二维雷达、STL-19P 扫描、IMU、连续里程计、地图、代价地图、规划路径、定位诊断、四路普通相机与深度相机均保留。视觉识别、目标板位姿和实际对桩程序有对应接口，未启动时仍显示等待，不拿 ArUco 二维框代替位姿。

旧 `#npu` 链接自动回到总览。旧相机协议键仍可用于兼容及历史数据，不作为当前新画面入口。日志分类、每日测试、视频与识别叠加、覆盖盲区配置不在本次删除范围。
